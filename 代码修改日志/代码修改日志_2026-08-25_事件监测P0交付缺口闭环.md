# 代码修改日志：事件监测 P0 交付缺口闭环（2026-08-25）

## 变更目标

依据 `产品文档/事件监测模块_阶段11全量验收与交付报告_v0.1.md` 的建议，仅关闭已批准 P0 缺口；未扩展 P1/P2。

## 主要变更

| 范围 | 变更内容 |
| --- | --- |
| 来源接入 | 新增来源告警到 MonitoringEvent 的确定性投影；保留人工确认状态，只更新规则建议等级。 |
| 运行编排 | 新增 `MonitoringDemoRuntime`，串联模拟适配器、Store、仓储、游标补拉与页面状态。 |
| 原子持久化 | Alarm、Receipt、Event 与接入审计统一提交；新增监测数据清理仓储接口。 |
| 消息处理 | 接入 `source_alarm`、`source_clear` 与 `evidence_status`；重复消息不覆盖本地新版本。 |
| 页面入口 | 新增六场景选择、固定 seed、暂停/继续、断线恢复、视频故障、人工补报和清理工具栏。 |
| 核实草稿 | 未提交表单按事件与用户写入 sessionStorage，刷新恢复并提示，提交后清理。 |
| 权限边界 | 以具体演示设施白名单覆盖 G50/G75 场景，不扩大道路级角色权限。 |
| 应用装配 | 应用初始化后连接模拟监测运行时；事件监测视频/GIS视图共享场景数据。 |
| 文档 | 更新 `demo/README.md`，新增阶段11验收报告 v0.2。 |

## 新增自动化覆盖

- 来源告警创建、连续告警合并、建议等级升级且不覆盖人工确认。
- 异常停车 12→1 与解除关闭、消息重放幂等、持续观察新证据复核、L4 建议不自动确认。
- 六类固定场景完整业务结果。
- 断线期间本地认领、恢复补拉、游标与版本保护（AC-23）。
- 人工补报复用同一标准化入口。
- 仓储接入事务失败回滚与清理后唯一索引复用。
- 清空监测数据不改变智能管控运行态。
- 无活动场景的视频故障降级、已关闭历史阻止未清理重载。
- 核实草稿保存、恢复、用户隔离与损坏数据容错。

## 未改变的边界

- 未接入真实 AI 视频、WebSocket、雷达、物联网、第三方事件或生产数据库。
- AI/规则只给建议等级；确认、误报与关键订正仍由有权限用户提交。
- L4 仅在人工确认后自动接管；接管不自动下发交通控制措施。
- 未实现 PRD 的 P1/P2 能力。
- 浏览器自动化连接因 Windows sandbox 初始化失败，视觉/响应式/真实浏览器时延与 AC-19 两小时墙钟堆验收仍待环境恢复后执行。
