# 代码修改日志：处置指令回执与基础设施联动（2026-08-08）

## 变更摘要

在“统一处置时序”中增加模拟指令下发回执，并将成功下发的设备指令同步到事故点上下游基础设施网格图与 GIS 地图。设备离线时产生失败回执，不触发设备状态变更。

## 功能变更

| 范围 | 变更内容 |
|---|---|
| 操作项确认 | 确认操作项时生成系统、人员、设备三级模拟回执，状态支持成功、部分成功和失败。 |
| 回执明细 | 已下发操作项可展开查看目标类型、目标名称、确认耗时与失败原因。 |
| 设备状态 | 全幅封道、车道封闭、分流诱导、隧道通风等操作会生成对应的设备显示内容及颜色。 |
| 基础设施网格 | 成功同步的设备显示“已同步”和关联操作项；离线失败设备保持原有状态。 |
| GIS 地图 | 已同步设备采用指令语义色高亮，并在标记名称中显示“已同步”。 |
| 布局保护 | 基础设施网格的横向溢出限制在自身滚动容器内，避免影响右侧门架通行能力图表。 |

## 代码清单

| 文件 | 说明 |
|---|---|
| `demo/src/domain/plan.ts` | 增加下发状态、下发目标、设备指令效果和操作项回执模型。 |
| `demo/src/engine/commandDispatch.ts` | 生成模拟下发回执，处理离线设备失败，并聚合当前事件成功同步的设备指令。 |
| `demo/src/store.ts` | 操作项确认时写入回执与设备同步效果。 |

| `demo/src/engine/infrastructureMonitor.ts` | 将成功设备指令覆盖到基础设施监测内容与颜色。 |
| `demo/src/components/InfrastructureMonitorGrid.tsx` | 显示设备“已同步”标识和关联操作项。 |
| `demo/src/components/GisNetworkMap.tsx` | 将同步设备映射为 GIS 高亮标记。 |
| `demo/src/gis/amapTwinOverlays.ts` | 使同步设备采用强调样式渲染。 |

## 影响与回退

- 本次能力仅使用前端模拟回执，不调用真实外部系统或设备接口。
- 回退时可移除 `commandDispatch.ts` 的调用，并删除 `PlanMeasure.dispatch` 字段；原有操作项确认、GIS 与设备监测功能仍可独立运行。
