# 代码测试与审计报告（2026-07-30）

## 结论

本轮对 `demo` 开展静态检查、全量单元测试、TypeScript 类型检查、生产构建、依赖树与离线安全审计，并针对高德单引擎地图重构进行专项回归。质量链全部通过，可继续用于本地演示与研发联调。

## 覆盖范围

- 高德地图 JS API 加载、安全密钥配置与地图实例生命周期。
- 高德原生路线、互通、设施、应急资源、事件、拥堵、管控、队尾、预测兑现和雷视覆盖物。
- 左侧事件列表选中后高德地图聚焦；摄像机、事故点和雷视目标的点击联动与详情弹窗。
- 2D/3D、全线视角、主题切换、事件孪生与视频视图。
- 旧 MapLibre/Leaflet 代码、依赖、样式与文档残留。

## 发现与修复

1. 左侧事件列表聚焦仅在“事件孪生”视图执行，导致路网态势下不定位。已改为任何 `focusedEventId` 变化均调用高德 `setZoomAndCenter`。
2. 移除旧地图依赖后，`@types/geojson` 不再由传递依赖提供，导致生产构建失败。已改为显式开发依赖并锁定到 `package-lock.json`。
3. 新增 `amapTwinOverlays.test.ts`，验证路线、设施、资源、事件均生成高德原生覆盖物，并验证摄像机点击回调。
4. 清理 MapLibre 与 Leaflet 组件、依赖和样式；README 更新为高德单引擎技术口径。
