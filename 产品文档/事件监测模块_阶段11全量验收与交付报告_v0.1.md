## 8. 浏览器与响应式验收

本地Vite服务可启动，生产构建成功。但内置浏览器自动化运行时在执行最小探针前退出：

```text
node_repl kernel exited unexpectedly
windows sandbox failed: helper_unknown_error: setup refresh had errors
```

因此以下项目均为未完成，而非通过：

- Chrome最新版及前一主要版本首屏、Tab、列表、抽屉、GIS和接管冒烟；
- Edge最新版及前一主要版本冒烟；
- 1920×1080主视口和1280px最低宽度；
- 首屏≤3s、新事件≤1s、详情≤1s、接管反馈≤3s的浏览器实测；
- 真实浏览器连续2小时无崩溃和稳定堆增长≤100MB。

## 9. P0交付缺口

以下项目属于已批准P0，不得归入“后续优化”：

1. 建立`DemoMonitoringAdapter → normalize → receipt/alarm持久化 → aggregation → MonitoringEvent → Store/UI`运行编排，并处理source_clear与evidence_status。
2. 为六个固定场景提供可执行入口，完成场景级端到端自动化或人工验收脚本。
3. 将源连接恢复后的`pullAfter(globalCursor)`与Store持久化、幂等和版本保护连成单一链路，补齐AC-23。
4. 将未提交核实表单写入sessionStorage并提供刷新恢复提示。
5. 补齐人工补报进入同一标准化入口的可操作入口或明确从P0移除。
6. 浏览器执行环境恢复后完成冒烟、响应式、时延和AC-19两小时堆验收。

在上述缺口关闭前，不应将“事件监测MVP”标记为正式验收通过。

## 10. P1/P2未实现清单

### P1未实现

- 隧道异常、桥梁异常、山体滑坡/边坡异常的专业平台事件结论接入。
- 雷视融合事件源和相邻摄像机联动。
- GIS热力图、区域排行、类型分布和时段趋势。
- 跨机构协同。
- 监测业务导出及对应权限、脱敏和审计闭环。
- 算法效果指标页面：人工确认率、误报率、样本量、人工标注覆盖率及“样本不足”提示。当前只有原始计数准备函数。

### P2未实现

- 真实AI视频、雷达、物联网、设施平台和第三方平台接入。
- 真实REST/WebSocket/视频流、服务端数据库和对象存储。
- 统一身份认证、生产组织权限和跨机构协同制度。
- 生产通知渠道。
- 桥梁、边坡和隧道原始传感器诊断。
- 自动执行交通控制措施。

## 11. 风险与待决项

- 真实AI事件编码、视频协议、受控证据地址和脱敏素材仍未确定。
- 数据保留期限、生产审计要求和统一认证规则未确定。
- 通用安全研判只能产生PlanningGap；新增事件类型的专属管控规则尚未补齐。
- 当前主JS产物约974kB，Vite提示大包风险未触发失败，但生产化前应评估按模块拆分。

## 12. 阶段结论与下一步门禁
